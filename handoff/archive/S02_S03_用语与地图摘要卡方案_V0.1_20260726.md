## 2. S03 办理状态用语

### 2.1 问题

| 现状展示 | 观感问题 |
|----------|----------|
| 调查中 | 偏「内部排查」口语，缺少「工资类上访/投诉事项」台账语感 |
| 协调中 | 易与一般「协调会」混淆，未体现化解/催缴/多方会商 |
| （已办结） | 可用；宜与甲方「建设单位评估确认」叙事衔接，不必改词本身 |

甲方已明确口径（内容打磨 V0.1）：统计范围偏 **农民工工资方面上访**；办结由 **建设单位评估确认**。既有资料**未给出**固定的办理状态枚举表 → 下列推荐为「行业习惯 + 甲方已有表述」推演，**须勾选确认**。

### 2.2 行业 / 甲方对照（可引用习惯，非法定枚举）

| 习惯阶段（建设领域劳务/工资争议台账常见） | 甲方已有表述 | 与现状对应 |
|------------------------------------------|--------------|------------|
| 登记 / 受理 | 上访事项纳入台账；一事项一编号 | （本轮明细未单独展示「受理」态） |
| 核查 / 核实 | 工资类事实核对（人数、金额、标段） | ≈ 调查中 |
| 协商化解 / 催缴督办 | 多方协商、支付督促 | ≈ 协调中 |
| 办结确认 | **建设单位评估确认**办结 | ≈ 已办结 |

信访/投诉类对外话术常见「受理—办理—办结」；农民工工资专项常见「核查—化解—销号/办结」。本产品 KPI 已用「未办结 / 办结」，**办理中细分不宜再用过于口语的二字词**。

### 2.3 推荐词表（现状 → 建议）

| 现状展示 | 建议展示（首选） | 备选 | 语义说明 |
|----------|------------------|------|----------|
| 调查中 | **核查中** | 事实核查中 / 情况核实中 | 强调工资事实、人数金额核实，非泛化「调查」 |
| 协调中 | **协商化解中** | 协调处理中 / 多方会商中 | 体现化解导向；避免单字「协调」过轻 |
| 已办结 | **已办结**（保持） | 建设单位已确认办结（详情脚注） | 列表保持短词；详情区可脚注甲方确认 |

**不推荐本轮采用：**「处理中」「跟进中」「进行中」（过空）；「立案」「侦办」（司法语感）；UI 出现「演示/测试」角标（已禁）。

### 2.4 是否改数 / 只改展示文案

| 项 | 建议 | 说明 |
|----|------|------|
| DB / seed 字段值 `调查中`/`协调中` | **本轮可不改** | 首页已有 demo 数据；避免牵动分布图、筛选、测试断言 |
| 前端 / API **展示映射** | **推荐** | `调查中→核查中`，`协调中→协商化解中`；内部码可仍用原值 |
| KPI 未办结计数 | **不动** | 与用语无关 |
| 正式态主值 0 | **不动** | 已按内容打磨实施；与本方案解耦 |

**结论：** 优先 **只改展示文案映射**；若你希望库内枚举与屏上完全一致，再单开「改 seed + 兼容旧值」小任务。

## 3. S02 流程用语

### 3.1 是否符合专业流程（明确结论）

**结论：基本符合建设领域较大/重大风险管控习惯；进度轨四步短标「在管 + 管控」部分需口语化脚注或微调，避免与列表态「持续管控」叠词误解。**

对照习惯（危大工程 / 风险分级管控常见叙事，非逐字国标条文）：

| 行业习惯环节 | 现网用语 | 符合度 |
|--------------|----------|--------|
| 风险辨识（登记） | 辨识 | 符合 |
| 评价 / 评估 / 分级后纳入管控清单 | （进度轨用「在管」代替） | **部分口语化**：甲方 KPI 强调「在管」，合理，但不宜与下一步「管控」并列为无解释二字词 |
| 落实措施、监测、巡查（持续管控） | 管控（轨）+ 持续管控（列表） | 符合「管控」语义；**轨与列表用词宜分工** |
| 解除 / 降级 / 完工销号（建设单位评估） | 销号 / 已销号 | 符合；与甲方「建设单位确认」一致 |

「销号」「在管较大及以上」「持续管控」与 S02 V0.2 甲方对照表一致，**建议保留业务语义**，只梳理展示层级。

### 3.2 推荐展示文案

#### A. 进度轨四步（L2 顶栏）

| 方案 | 四步展示 | 适用 |
|------|----------|------|
| **A1 推荐（少改业务、加脚注）** | 辨识 → 在管 → 管控 → 销号 | 保持现结构；轨旁脚注：「在管＝纳入在管清单；管控＝措施落实与监测」 |
| **A2 更贴行业四字链** | 辨识 → **评估** → 管控 → 销号 | 「评估」对应分级/准入在管；列表仍用「持续管控/已销号」 |
| **A3 与历史注释对齐（稍长）** | 辨识登记 → 进入在管 → 持续管控 → 销号评估 | 信息最清楚；需确认轨宽与换行 |

**默认推荐：先 A1（脚注澄清）**；若你认为屏上必须「辨识—评估—管控—销号」视觉链，再选 **A2**（仅改进度轨第三前字「在管→评估」，**不改** `control_status` 枚举）。

#### B. 列表 / 徽章状态（L1 清单、L2 当前状态）

| 现状 | 建议 | 说明 |
|------|------|------|
| 持续管控 | **保持** | 甲方/V0.2 已定；表示仍处于措施落实与监测 |
| 已销号 | **保持** | 与 KPI「<>已销号」一致 |
| 建设单位确认在管 | **保持**（详情脚注） | 非列表主状态词 |

### 3.3 避免叠词「在管 + 管控」造成误解

| 易混点 | 澄清（建议写进 UI 脚注或帮助一句） |
|--------|-------------------------------------|
| KPI / 侧栏「在管」 | **集合属性**：较大/重大且未销号，计入口径 |
| 进度轨「在管」 | **过程节点**：已登记并进入在管清单（起点） |
| 进度轨「管控」 | **过程节点**：管控措施已落地、处于监测巡查 |
| 列表「持续管控」 | **当前业务状态**：尚未销号的在管项日常态 |

规则：**进度轨用过程词；列表用状态词；二者不要再用同一「管控」当唯一区分。**  
若选 A2，则轨上不再出现孤立「在管」，叠词压力下降。

## 4. 地图右下角摘要卡：暂隐方案

### 4.1 目标

选中 S02 风险点时，**暂不展示**右下角 `S02MapSummaryCard`（及同风格「再点一次看详情」浮层），降低与左上 L2 的双卡片重复。

### 4.2 隐藏条件（确认后实施时的建议）

| 条件 | 行为 |
|------|------|
| S02 工作台打开且已选中风险点 | **不渲染**右下角摘要卡 |
| S02 工作台打开但未选中 | 本来无摘要卡；不变 |
| 非 S02（E01 等其他摘要卡） | **本方案不要求一并隐藏**（可另案） |
| 用户从摘要卡「查看管控详情」的旧入口 | 改由下列保留入口承担 |

### 4.3 仍保留的入口（L2 / 侧栏）

- 右侧 **S02WorkspacePanel** 清单行点击 → 地图高亮 + **L2** `S02ClosureAnalysisPopover`
- 地图要素点选（含多风险选择器）→ 同上 L2
- L2 内「管控进展 / 管控材料」Tab、关闭 × 取消选中

摘要卡能力（措施摘要、再开 L2）由 L2 顶栏字段覆盖即可。

### 4.4 实施约束

- **待你确认本方案勾选项后再改代码**
- 隐藏方式优先：条件不挂载 / `v-if`；组件文件可保留，便于日后恢复
- 日后恢复时：评估是否改为「仅窄屏显示」或「L2 收起时显示」——记入债务，本轮不定
