## 2. 模块 A — Workspace 顶栏入口与壳层

### 2.1 顶栏顺序（唯一合法）

```text
工作台首页  →  ESG智能助手  →  数据填报
     /              /assistant         /workspace
```

- `navItems` 增加 `{ key: 'workspace', label: '数据填报' }`，排在 `assistant` **之后**  
- `DashboardPage` / `AssistantPage` / `WorkspacePage`：`handleNavClick`（或等价）互通：  
  - `dashboard` → `/`  
  - `assistant` → `/assistant`  
  - `workspace` → `/workspace`（可选默认 `?t=workspace`）  
- 在 Workspace 时顶栏第三项 `active`  
- **禁止**把概览/任务/智能入库/审核/资料中心做成顶栏一级项  

### 2.2 模块内二级导航（须保留 5 项）

| 顺序 | key | 标签（本单） | 说明 |
|------|-----|--------------|------|
| 1 | `workspace` | **填报概览** | 由「工作台首页」改名，避免与顶栏第 1 项撞名 |
| 2 | `tasks` | 我的上传任务（可保留现文案） | 保留 |
| 3 | `smart-upload` | ESG智能入库 或简称「智能入库」 | 保留；简称可选 |
| 4 | `review` | 审核管理（可略缩「审核」） | 保留 |
| 5 | `documents` | 资料中心与档案（可略缩「资料中心」） | 保留 |

- Tab 切换建议 `router.replace` 同步 `?t=`（方案推荐；若现有已读 query，至少保持深链可读）  
- 深链示例：`/#/workspace?t=smart-upload`、`/#/workspace?t=review`  

### 2.3 壳层统一（80px HeaderNav）

| 项 | 要求 |
|----|------|
| 参考 | `AssistantPage.vue`：`HeaderNav` + `height: var(--dashboard-header-h)`（**80px**） |
| WorkspacePage | **接入**平台 `HeaderNav`；在 Workspace 时第三项 active |
| WorkspaceNav | **去掉/自隐**与平台顶栏冲突的自有绿系标题栏、重复用户区/铃铛；**保留**二级 Tab 作为顶栏下方 sub-nav |
| 视觉 | 不强制整页换肤；避免双顶栏叠高、双套品牌导航 |

### 2.4 迷你助手降级（低成本必做）

填报概览右侧「迷你 ESG 智能助手」：

- **优先：** 改为明确链接/按钮跳转 `/#/assistant`（或 `router.push('/assistant')`）  
- 可保留轻量快捷问句 UI，但**不得**表现为第二套完整对话产品  
- 若改动面过大：至少去掉独立会话产品感，改为「打开 ESG 智能助手」入口——在交付说明注明取舍  

### 2.5 建议必改文件（Workspace）

| 文件 | 动作 |
|------|------|
| `src/data/dashboard.mock.ts`（及若存在的 store/nav 同源） | `navItems` 增加「数据填报」 |
| `src/data/master.mock.ts` | 若维护同源 nav，一并同步 |
| `src/components/layout/HeaderNav.vue` | 确认三项宽度在 1920 壳不换行（必要时微调，勿改 80px 高度语义） |
| `src/views/DashboardPage.vue` | nav 跳转含 workspace |
| `src/views/AssistantPage.vue` | nav 跳转含 workspace；作 80px 壳参考 |
| `src/views/WorkspacePage.vue` | 挂载 `HeaderNav`；active=workspace；保留五 Tab |
| `src/components/workspace/WorkspaceNav.vue` | 去重顶栏；sub-nav；首 Tab 文案「填报概览」 |
| `src/components/workspace/WorkspaceHome.vue`（或迷你助手所在组件） | 助手降级为链到 `/assistant` |
| `src/router/index.ts` | **通常不改路由 path**；仅确认 `/workspace` 仍指向 WorkspacePage |
