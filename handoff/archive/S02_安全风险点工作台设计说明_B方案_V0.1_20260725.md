## 1. 目标与边界

首页点击 **S02 KPI**，或地图业务链/安全风险点空间对象点击 → 进入 **E01 同等格式** 的地图中心工作台：

- 右侧一级总览（等级筛选 + 清单分页）
- 地图高亮对应 GIS 要素；工具栏「安全风险点」开关与工作台一致
- 选中后地图角摘要卡展示管控要点（非稀疏全屏弹窗）

### 1.2 本阶段不做

- 不回退 / 不改动 S01 数据层与 S01 UI 回退轨道
- 不推倒首页 ESG 总布局；不改 E01–E04 / S03–S04 / G 组
- 不做真实督办审批流、不做「演示/测试/未确认」UI 角标
- 不做 E02 级完整闭环案卷二级壳（进度轨/证据页）；摘要卡字段够用即可

### 1.3 成功标准（本轮）

## 2. 口径与主源

### 2.1 KPI 口径（沿用现网）

在管 **较大及以上** 安全风险点数：

```sql
SELECT COUNT(*) FROM safety_risk_point
WHERE risk_level IN ('重大', '较大')
  AND control_status <> '已销号'
```

一风险点计 1；已销号不计。

### 2.2 工作台列表主源

唯一读表：`safety_risk_point`（与现 `get_s02_safety_risk_detail` 同源）。

概览统计：

| Tab | 含义 |
|-----|------|
| 全部 | 在管较大+重大合计 |
| 重大 | `risk_level='重大'` |
| 较大 | `risk_level='较大'` |

附加只读摘要（可不进 Tab）：本月新增、本月销号、涉及工点——沿用现明细 API 口径。

### 2.3 GIS 挂接（已知映射，可构造补点）

与现网 `s02_gis_feature_map` / TrafficGisOverview `S02_FEATURE_IDS` 对齐：

| 业务码 | rawId | 主要素 | 备注 |
|--------|-------|--------|------|
| S02-002 | 430002 | `section-2-1` | 高边坡坍塌风险 |
| S02-006 | 430006 | `slope-2-1`（主）+ `section-3-1`（辅） | 与 gis_business_summary 一致 |

未挂接项：`canLocate=false`，清单仍展示，点击不飞地图。

## 3. 信息架构（对标 E01/E02）

```
首页
 └─ 点 S02 KPI / 地图 S02 业务链
      ├─ 右侧 S02WorkspacePanel（L1）
      │    ├─ 等级统计 Tab
      │    ├─ 风险点清单（分页）
      │    └─ 关闭 → 恢复地图状态

           ├─ 关联要素高亮（复用 E02 selection visual）
           ├─ S02MapSummaryCard（选中时）
           └─ 工具栏「安全风险点」开关
```

视觉：面板壳同 E01/E02（圆角暗底、统计格、行卡、分页）；主题强调色用 **S 组蓝 `#2f9cff`**（与 E 组绿/橙区分）。

## 6. 验收点击路径

1. 启动前后端 → 首页点 **S 组「在管较大及以上安全风险点数」**  
2. 右侧出现「在管安全风险点」面板；地图高亮相关落点集合  
3. 点「重大」Tab → 列表收缩；点一条可定位项 → 地图飞至要素 + 右下角摘要卡  
4. 地图点空白 → 取消选中；点面板 × → 退出工作台，恢复侧栏合规/碳/月报  
5. 工具栏关闭再打开「安全风险点」→ 落点显隐与强调一致
