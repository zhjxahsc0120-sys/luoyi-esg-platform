## 本轮改动（仅文案、口径、色态、必要图层开关）

### A. G03 参建单位履约评价
- 首页不再展示无意义 `0家`
- 主数字：`displayText: '待评价'`，`unit: ''`，`ledgerStatus: 'pending'`
- Mock + `mysql_api.py` KPI 聚合同步下发 `displayText` / `hint` / `ledgerStatus`
- 详情继续空态（不编造排名）

### B. 综合风险四卡（红 / 黄 / 蓝 / 总数）
- 标签：红色预警 / 黄色预警 / 蓝色提醒 / 风险事项总数
- 含义：立即督办 / 重点关注 / 持续跟踪 / 事项汇总
- `tone: 'red'|'yellow'|'blue'|'neutral'` → 数字色 + 边框 + 弱底色 + 图标
- 组件：`ComplianceRiskPanel.vue`（主站）；`MasterCompliancePanel.vue` 同步色态

### C. 红黄蓝预警清单
- 保留「预警构成」+「重点风险事项」
- 右侧新增「红黄蓝预警清单」：等级 / 事项 / 来源(E/S/G) / 状态 / 时间；红优先
- 后端 `get_compliance_panel_data` 增加 `warningItems`；store 接线渲染

### D. S03 / S04 / G01 / G02 展示增强（不改布局）
| 指标 | 增强 |
| --- | --- |
| S03 | 首页 `hint`：工资发放达标率（有 `salary_payment_record` 则实算，否则「暂无评价数据」）；实名覆盖率无台账 → 「暂无评价数据」 |
| S04 | `hint` / 详情摘要：投诉数量、信访数量、化解率（可算则算，否则诚实空文案） |
| G01 | 详情/摘要关键手续清单：环评批复√ / 水保批复√ / 施工许可√（按手续名匹配，无涉密文件） |
| G02 | 详情摘要：问题数量 / 整改数量 / 闭环率 |
| E01–E04 / S01 / G04 | 维持 V1.0 名称与口径；E03 首页仍为聚合 |

### E. GIS 图层入口
- 保留地图组件与尺寸
- `MapChrome` / `TrafficGisOverview`：保留环境监测点、安全风险点；**新增**生态保护点、群众诉求点开关
- 生态保护点：开关过滤 `ecological-zone` / `spoil-site`
- 群众诉求点：开关预留 `appeal-point`（当前可无要素，后续扩展）

## 诚实数据缺口

- G03 履约评价台账未建 → 「待评价」
- `salary_payment_record` 常为空 → 工资达标率「暂无评价数据」
- 无实名制覆盖率表 → 「暂无评价数据」
- 群众诉求 GIS 点位层尚未落库 → 开关可用、要素可为空

## 验收要点

1. G03 首页为「待评价」，非「0家」
2. 综合风险四卡一眼可辨红黄蓝
3. 右侧可见预警清单且红优先
4. S03/S04/G01/G02 有 hint 或详情补充口径
5. GIS 工具条可见生态保护点 / 群众诉求点开关；地图尺寸不变
6. 布局与 V1.0 壳层一致
