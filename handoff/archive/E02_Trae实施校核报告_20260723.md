## 阻塞问题（已修 / 待你复跑迁移）

### 1. `V1_1_044` 与 V1.1 表结构严重不匹配（已重写）

原种子问题包括：

- `e_case_status_history`：用了 `operated_at`，缺 `sequence_no` / `action_at` / `client_request_id` / `data_nature`
- `e_case_party`：用了 `person_name`/`contact_phone`，缺 `user_name`/`valid_from`/`data_nature`
- `e_case_evidence`：写了不存在的 `evidence_kind/title/description/file_asset_id`，且违反 `document_id OR file_id` 非空约束
- `gis_feature_business_relation`：写了不存在的 `business_type/business_key/is_demo`
- GIS id `section-1-2` / `section-2-2` 很可能不存在（FK/定位失败）
- **D03 `issue_type='水土保持'`** 违反 E02/E03 边界

**本轮：** 已用对齐现网结构的 `V1_1_044__e02_demo_seed.sql` 替换；D03 改为「弃渣场管理」；GIS 仅用 `section-1-1/2-1/3-1`、`eco-1-1`；D05 销项走 `document_record` + `CLOSURE_DOCUMENT`。

### 2. API 查询列名错误（已修）

- 列表/详情 GIS：改为 `relation_type` + `source_id`/`relation_code`
- 证据：改为 join `document_record` 取名称/说明
- 退回后再整改：材料完整度不再把上轮整改材料算作本轮已齐
- 旧 `get_e02_env_issue_detail`：补上 formal/demo 过滤，避免正式弹窗混数

### 3. 一级筛选 camelCase 映射错误（已修）

`PENDING_REVIEW.toLowerCase() === 'pending_review'`，而 API 返回 `pendingReview` → **待复查/待销项筛选为空**。  
已在 `E02WorkspacePanel` 与 `DashboardPage` 改为显式映射表。
