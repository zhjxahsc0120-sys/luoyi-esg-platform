## 1. 总体设计

### 1.1 分层

```
字典/组织账号
    ↓
工作台上传任务 / 资料主档 / 智能入库(AI解析)
    ↓
E/S/G 业务台账与闭环（E01监测链 · E02/E03问题 · E04碳 · S01确认 · G合规）
    ↓
指标结果 / 首页快照 / GIS / 月报专题
```

### 1.2 横切约定

| 约定 | 说明 |
| --- | --- |
| `data_nature` | 常见取值 `formal` / `demo` /（部分）`platform_calc` |
| `is_demo` | 演示数据闸；与首页/助手 scope 对齐时需同源 |
| `effective_status` | 如 `DRAFT` / `EFFECTIVE` / `INEFFECTIVE`（E03/S01/E04 等） |
| 闭环案件 | `e_closure_case` 域跨 E01 事件与整改；状态历史建议 append-only |
| 迁移登记 | `esg_schema_migration_history` 记录已执行脚本 |
