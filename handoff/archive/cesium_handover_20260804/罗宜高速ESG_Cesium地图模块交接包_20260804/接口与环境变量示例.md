# 接口与环境变量示例

## 环境变量

```env
# 可选。未配置时使用 /api/esg/gis
VITE_TRAFFIC_API_BASE=/api/esg/gis

# 可选。未配置时使用模块内默认在线底图
VITE_TRAFFIC_BASEMAP_URL=

# 可选。未配置时使用模块内默认在线地形
VITE_TRAFFIC_TERRAIN_URL=
```

不要把 API Key、数据库密码或真实 Token 写入前端代码和本交接包。

## Vite 本地代理

```ts
server: {
  proxy: {
    '/api': {
      target: 'http://127.0.0.1:8765',
      changeOrigin: true,
    },
  },
},
```

## 接口通用响应

```json
{
  "code": 0,
  "data": []
}
```

## 图层接口

```text
GET /api/esg/gis/layers?projectId=LUOYI-ESG
```

正式首页图层的 `source` 应为：

```json
{
  "type": "api"
}
```

不要为动态业务图层设置静态 `source.url`，否则 `dashboard` 模式会将其视为旧静态图层并过滤。

## 要素接口

```text
GET /api/esg/gis/features?projectId=LUOYI-ESG&layerId=env-monitor-upload
```

坐标使用：

```json
{
  "type": "Point",
  "coordinates": [108.75, 24.55, 0]
}
```

顺序必须是 `[经度, 纬度, 高程]`。
