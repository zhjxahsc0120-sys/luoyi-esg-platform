## 1. 导航命名与路由（已选定）

### 1.1 文案选型

| 候选 | 评价 |
|------|------|
| 碳与月报 | 短，但「碳」边界不清 |
| **碳核算与月报** | **推荐**：对齐 E04「累计碳排放 / 核算边界」+ 月报运营，顶栏可读 |
| 低碳与月报 | 偏减排叙事，与当前主指标「累计排放」略偏 |

**冻结推荐：** 顶栏与页标题均用 **「碳核算与月报」**。

### 1.2 路由

| 项 | 值 |
|----|-----|
| Hash 路由 | **`/#/carbon-report`**（`name: 'carbon-report'`） |
| 备选（勿并行落地） | `/#/esg-carbon` |
| 深链 | `?t=` 同步二级 Tab，例：`/#/carbon-report?t=carbon-overview` |

### 1.3 顶栏顺序（HeaderNav / `navItems`）

```
工作台首页 → ESG智能助手 → 数据填报 → 碳核算与月报
```

`key` 建议：`carbon-report`；`label`：`碳核算与月报`。

平台壳导航跳转需在 **Dashboard / Workspace / Assistant / 本页** 四处 `handleNav*` 中补一条 `carbon-report` → `router.push('/carbon-report')`（最小接线；**禁止**改 HeaderNav 视觉结构）。

## 2. 壳层与版式规则（MUST）

与 Workspace / Dashboard / Assistant **同一大屏壳**：

1. 外层：`screen-wrapper` + **`screen-canvas` 1920×1080 + scale**（对齐 `WorkspacePage`）
2. 顶区：`HeaderNav`，高度 `var(--dashboard-header-h, 80px)`
3. 二级：仿 `WorkspaceNav` 的 Tab 条（本页私有 `CarbonReportNav`）
4. 主区：可读运营工作台；优先复用 **Workspace** 视觉语言：`.ws-panel` / `.ws-btn-*` / `--ws-*`（`workspace.scss` 可按需 import，或新建 `carbon-report.scss` **仅扩展同类 token**，禁止新色板 / 紫系 glow / 演示 chrome）
5. 背景：与 Workspace 同系深色渐变（`#020b18` → `#051a32`）
6. **禁止**：首页右栏组件视觉克隆；「演示 / 测试 / 未确认」UI chrome；把本页五个子能力塞进平台顶栏

## 3. 信息架构（IA）

深度对齐 Workspace（顶栏一级 + 页内二级 Tab），推荐 **四个二级 Tab**（碳二 + 月报二）：

| `?t=` key | 标签 | 模块 | 一句话职责 |
|-----------|------|------|------------|
| `carbon-overview` | **碳概览** | 碳 | 累计排放主值、构成、口径说明 |
| `carbon-detail` | **碳明细** | 碳 | 边界/来源/活动列表化只读；**不以打开旧 E04 模态为主路径** |
| `monthly-prep` | **月报准备** | 月报 | 归集进度、状态计数、待办清单 |
| `monthly-output` | **月报输出** | 月报 | 输出/归档摘要（有数据则展示；无则空态） |

默认 Tab：`carbon-overview`。

> 备选（不推荐首发）：单页上下两大段「碳模块 | 月报模块」。四 Tab 更易与 Workspace 操作习惯对齐，且利于深链。

## 4. 各 Tab 内容规格

### 4.1 碳概览（`carbon-overview`）

**目标：** 一眼看清「累计多少、从哪来、边界是什么」。

| 区块 | 内容 | 数据 |
|------|------|------|
| 主 KPI | 项目累计碳排放；单位 tCO₂e；展示可取整，**禁止硬编码 6175** | `GET /api/dashboard/panels` → `carbon.metrics`（与首页面板同源） |
| 构成 | 来源占比列表或简洁分段（油 / 电 / 材料等 `carbon.sources`） | 同上 `carbon.sources` |
| 口径说明 | 固定说明卡（只读文案）：施工用油 + 用电 + 主要材料；**运输暂不纳入**；统计起点 **2026-05-08**；当前核算期 **2026-05 — 2026-07**；精确累计约 **6174.99**（以 API/库为准） | 甲方 7.14 / E04 基线文档；数值仍走 API |
| 可选次级 | 减排/措施摘要一行（若 panels 有 `reductions`）；不强制大环图 | panels |

可选「打开完整核算视图」：可 **懒挂** 既有 `E04CarbonEmissionModal` 作补充，**不得**作为本 Tab 唯一内容。

权威口径摘录：`_handoff/E04_甲方7.14数据重构与设计基线_20260724.md`。

### 4.2 碳明细（`carbon-detail`）

**目标：** 列表化边界与构成，运营可扫；**非**首页专题克隆、**非**强制旧模态。

| 区块 | 内容 |
|------|------|
| 边界表 | 纳入：燃油、电力、主要材料；不纳入：运输（暂）；设备不单列防双计 |
| 来源明细 | `sources` 名称 / 占比 / 可选量值（字段以 panels / benefit-overview 已有为准） |
| 可选扩展 | 若 `GET /api/carbon/benefit-overview` 有可用明细字段，只读表格展示；无则空态 + 口径提示 |
| 禁止 | 改 E04 模态内部；改 seed 主值；编造行 |

### 4.3 月报准备（`monthly-prep`）

**目标：** 当期月报就绪度运营台。

| 区块 | 内容 | 数据 |
|------|------|------|
| 期次头 | 报告期、期次名、截止区间 | `GET /api/monthly-report/readiness?reportPeriod=`（默认与 store 一致，如 `2026-07`） |
| 进度 | 归集率 %、已归集 n/m | readiness |
| 状态计数 | 待提交 / 待确认 / 待补正等 | readiness |
| 待办清单 | `exceptionTasks` 列表（可分页或滚动）；字段 `taskName` + `monthlyStatus` 等已有契约 | readiness |
| 可选 | 「打开月报专题」懒挂 `MonthlyReportModal`（补充，非主路径） | topic API 只读 |

### 4.4 月报输出（`monthly-output`）

| 区块 | 内容 | 数据 |
|------|------|------|
| 概览 | 若有：`GET /api/monthly/report-overview?reportMonth=` 只读摘要 | `getMonthlyReportOverview` |
| 空态 | 无数据时清晰空态（无演示角标） | — |
| 归档 | 若 overview 含归档/输出字段则列表；否则仅展示「本期输出状态」占位文案 | overview |

**Master mock：** 不以 Master 碳/月报 mock 为口径。
