## 1. 导航命名与路由

### 1.1 文案

**冻结：** 顶栏与页标题均用 **「月报」**（短、清晰）。

### 1.2 路由

| 项 | 值 |
|----|-----|
| Hash 路由 | **`/#/monthly-report`**（`name: 'monthly-report'`） |
| 深链 | `?t=` 同步二级 Tab，例：`/#/monthly-report?t=prep` |

### 1.3 顶栏顺序（HeaderNav / `navItems`）

```
工作台首页 → ESG智能助手 → 数据填报 → 碳核算 → 月报
```

`key`：`monthly-report`；`label`：`月报`。  
「碳核算」由姊妹页定义；本页实施时 **允许** 在 `navItems` 中一并挂上两项（最小接线），但 **禁止实现碳核算页内容**。

平台壳 `handleNav*` 需在 Dashboard / Workspace / Assistant / 月报页 /（若已存在）碳页中补 `monthly-report` → `router.push('/monthly-report')`。**禁止**改 HeaderNav 视觉结构。

---

## 2. 壳层与版式规则（MUST）

与 Workspace / Dashboard / Assistant **同一大屏壳**：

1. 外层：`screen-wrapper` + **`screen-canvas` 1920×1080 + scale**（对齐 `WorkspacePage`）
2. 顶区：`HeaderNav`，高度 `var(--dashboard-header-h, 80px)`
3. 二级：仿 `WorkspaceNav` 的 Tab 条（本页私有 `MonthlyReportNav`）
4. 主区：优先复用 **Workspace** 视觉语言：`.ws-panel` / `.ws-btn-*` / `--ws-*`（可 import `workspace.scss`，或新建 `monthly-report.scss` **仅扩展同类 token**）
5. 背景：与 Workspace 同系深色渐变（`#020b18` → `#051a32`）
6. **禁止**：首页 `MonthlyReportPanel` 布局克隆；演示 chrome；把碳内容塞进本页；以 `MonthlyReportModal` 作为整页唯一内容

## 3. 信息架构（IA · 仅月报）

| `?t=` key | 标签 | 一句话职责 |
|-----------|------|------------|
| `prep` | **准备进度** | 期次、归集率、状态计数、截止区间 |
| `todos` | **待办** | `exceptionTasks` 清单运营台 |
| `archive` | **输出归档** | 输出/归档摘要；无数据则空态 |

默认 Tab：`prep`。

### 3.1 文本线框

```
┌─ screen-canvas 1920×1080 ─────────────────────────────────────┐
│ [HeaderNav]  … │ 数据填报 │ 碳核算 │ 月报(active) │           │
│ [MonthlyReportNav]  准备进度 | 待办 | 输出归档                  │
│ ┌─ main (ws language) ───────────────────────────────────────┐ │
│ │  (active tab — monthly only)                               │ │
│ └────────────────────────────────────────────────────────────┘ │
└───────────────────────────────────────────────────────────────┘
```

## 4. 各 Tab 内容规格

### 4.1 准备进度（`prep`）

| 区块 | 内容 | 数据 |
|------|------|------|
| 期次头 | 报告期、期次名、截止区间 | `GET /api/monthly-report/readiness?reportPeriod=`（默认与 store 一致，如 `2026-07`） |
| 进度 | 归集率 %、已归集 n/m | readiness |
| 状态计数 | 待提交 / 待确认 / 待补正等 | readiness |

### 4.2 待办（`todos`）

| 区块 | 内容 | 数据 |
|------|------|------|
| 待办清单 | `exceptionTasks`（可分页或滚动）；`taskName` + `monthlyStatus` 等既有契约 | readiness |
| 空态 | 无待办时清晰空态（无演示角标） | — |

可选「打开月报专题」：可 **懒挂** `MonthlyReportModal` 作补充，**不得**作为本页唯一内容 / 主路径。

### 4.3 输出归档（`archive`）

| 区块 | 内容 | 数据 |
|------|------|------|
| 概览 | 若有：`GET /api/monthly/report-overview?reportMonth=` 只读摘要 | `getMonthlyReportOverview` |
| 归档 | overview 含归档/输出字段则列表；否则「本期输出状态」占位文案 | overview |
| 空态 | 无数据时清晰空态 | — |
