## 问题根因

当前分支 tip 对齐 `main`（Initial + 协作文档），**不是**已交付的 Cesium 大屏基线。首页表现为：

1. 顶栏文案错成「总览看板 / 数据填报与上传工作台」，且 `HeaderNav` 不可点击（无 `navigate` emit）。
2. `gisConfig.useRealGisOnDashboard = false` → 首页走 SVG 示意地图，而非 Cesium。
3. 缺少 `/assistant` 路由与 `AssistantPage`，无法形成「工作台首页 / ESG智能助手 / 数据填报」三页互通。
4. Trae 任务单合法改动（Workspace 壳、S03 展示映射等）叠在上述错误壳上，截图看起来像「假首页」。
