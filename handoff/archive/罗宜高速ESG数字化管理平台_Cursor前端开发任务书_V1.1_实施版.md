罗宜高速ESG数字化管理平台

Cursor前端开发任务书 V1.1（实施版）

一、文档定位

本文档用于指导Cursor进行罗宜高速ESG数字化管理平台前端增量开发。

本次开发基于现有前端系统，不重新设计平台，不替换现有架构。

开发依据：

1. AI开发冻结基线说明 V1.0

2. ESG指标体系及数据模型设计成果

3. 前端现状分析与设计说明 V1.0

目标：

在保持现有系统视觉、布局和技术架构不变的基础上，实现ESG指标体系、业务对象展示、风险预警和闭环管理。

二、当前前端基础约束

当前系统技术架构：

Vue3 + TypeScript + Vite

采用：

- 自研组件体系

- ECharts图表

- Cesium GIS

- Pinia状态管理

禁止修改：

1. 首页整体布局。

2. 1920×1080驾驶舱比例。

3. 左66% / 右34%布局结构。

4. 现有颜色、字体、组件风格。

5. 一级导航结构。

6. 技术框架和目录结构。

三、页面设计原则

本次ESG指标展示采用三种模式：

（一）工作台模式

适用于：

E01、E02、E03、E04、S02。

流程：

首页指标

→右侧工作台

→业务对象列表

→详情

→风险状态

→整改闭环

（二）弹窗模式

适用于：

S01、S03、S04、G01、G02、G03、G04。

流程：

指标卡

→详情弹窗

→统计信息

→明细数据

→趋势分析

（三）Workspace模式

适用于：

数据填报、智能入库、审核、资料中心。

四、首页改造要求

保持当前首页结构。

改造内容：

1. E/S/G指标数据接入。

2. 红黄蓝风险数量展示。

3. 指标点击下钻。

4. 与业务对象关联。

禁止：

新增首页大模块。

修改原有栅格。

十一、验收标准

必须实现：

1. 首页可展示ESG状态。

2. 指标可点击。

3. 页面可下钻。

4. 数据可追溯到业务对象。

5. 风险可展示。

6. 不破坏原有系统。
