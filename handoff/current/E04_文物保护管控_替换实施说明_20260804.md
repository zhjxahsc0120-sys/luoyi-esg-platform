# E04 文物保护管控替换实施说明（2026-08-04）

## 范围

首页 E04 由「项目累计碳排放」切换为「文物保护管控」：KPI 文案/数值、点击进入二级工作台、演示表与只读 API。

**未改动：**

- 首页 KPI 卡片壳布局/字号/颜色/间距
- 低碳增益专题（`CarbonBenefitPanel` / `CarbonBenefitModal` / `carbon_benefit_overview`）
- E01/E02/E03 工作台面板本体与其 GIS/API
- 碳排放表结构与 `get_e04_carbon_emission_detail`（仍保留，供碳专题/历史口径；首页 KPI/detail 不再走碳弹窗）

## 迁移

- 文件：`server/migrations/e_group_e01_v1_1/V1_1_052__e04_cultural_relic_demo.sql`
- 表：`biz_cultural_relic_object`
- 种子：3 条（K45+600 / K78+200 / K102+500）
- `project_id = LUOYI-ESG`，`section_id` 对齐既有 TJ-1/2/3

执行（DB 可用时）：

```bash
cd server
python -m migrations.e_group_e01_v1_1.migrate_v1_1
```

本机已执行迁移：`V1_1_052` → `[OK]`。若其他环境 MySQL 不可达：SQL 已入库；API 在缺表/空表时回退与种子一致的演示数据。

## 前端点击链路

`DashboardPage.handleKpiSelect('E04')` → `openE04Workspace()` → 右侧槽位渲染 `E04CulturalRelicWorkspacePanel`（同 E01–E03 工作台槽）。

不再调用 `getDashboardKpiDetail('E04')` 打开 `E04CarbonEmissionModal`。
