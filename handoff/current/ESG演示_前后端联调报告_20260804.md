## 2. API 集成矩阵

| Endpoint | 状态 | 说明 |
|----------|------|------|
| `GET /api/dashboard/kpis` | **wired** | 返回契约 `items[]` + 兼容 `groups[]`；`source=esg_demo` |
| `GET /api/dashboard/kpi/{key}` | **wired** | Demo 优先；含 `trend/summary/objects`；E04 四字段；G02/G03/G04 隔离 |
| `GET /api/dashboard/kpi/{key}/objects/{objectId}` | **wired** | 对象详情 + 关联风险 |
| `GET /api/dashboard/risk-warnings` | **wired** | `level/domain/kpiKey/objectId/objectName/responsibleUnit/status` |
| `GET /api/dashboard/panels` | **wired**（叠加） | Demo 风险写入 warningItems/metrics |
| `GET /api/environment/e04/cultural-objects` | **wired** | 文物 overview + objects；空态不编造 |
| `GET /api/dashboard/esg-home-status` | **missing**（有意） | 前端改用 kpis + risk-warnings 组合；失败才 mock |
| 旧 G02=整改 / G03=履约 / E04=碳 | **禁用（Demo 优先）** | 仅当 Demo 表缺失时才回落 legacy builder |

网络失败时：前端 `apiGet`→`null`→`loadError` / mock 标注 `source=mock`，**不**用假成功冒充 live。
