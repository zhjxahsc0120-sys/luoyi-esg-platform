## 3. mock fallback 情况

| 模块 | Silent mock on failure? | Mock 文件仍被 import? | 说明 |
|------|-------------------------|------------------------|------|
| **E01** | **NO** | **NO** | `getE01Events/Detail/Trend` 失败返回 `null`；面板错误+重试。`e01-workspace.mock.ts` 仍在磁盘（标注 OFFLINE），主路径未引用 |
| **E02** | **NO** | **NO** | 同上；`e02-objects.mock.ts` 磁盘保留、主路径断开 |
| **E03** | **NO** | **NO** | 同上；`e03-ecology.mock.ts` 磁盘保留、主路径断开 |
| **E04** | **YES** | **YES** | `api.ts` 仍 `import` `e04-cultural.mock`；HTTP 失败时 list 返回 `code:0` + mock（默认零对象领导态），detail 可 mock |
| **Homepage** | **YES（整页兜底）** | **YES** | `getEsgHomeStatus` 网络全失败 → `getEsgHomeStatusMock()`；`dashboard.store` 初始值来自 `dashboard.mock`，`loadKpis` 失败保留 mock groups。成功时 E 值来自 live overlay（`source=api` / 后端 `esg_demo`） |

代码证据（`src/services/api.ts`）：
- E01–E03：注释明确 *No silent mock fallback*；仅 type import，无 mock 模块 import。
- E04：`getE04CulturalObjects` 失败分支 `return { code: 0, data: getE04CulturalObjectsMock(), meta: { source: 'mock' } }`。
