# ESG 智能数据填报资料使用说明

本目录提供环境监测、水保整改和碳排放三类业务资料的 Excel 与 PDF 格式文件，用于智能数据填报页面的资料准备与结构化识别。

## 使用流程

1. 在“上传资料”步骤选择本地文件，或通过页面的快捷入口载入资料。
2. 检查文件名称、业务分类和预计记录数。
3. 启动 AI 解析，核对系统识别的字段与规则校验结果。
4. 对异常或近似匹配项进行人工确认。
5. 核对来源文件、目标台账和记录数量后生成入库清单。

## 文件要求

- 支持 Excel、CSV、PDF、Word、TXT 和压缩包。
- 同一批次可选择多个文件，建议保留原始文件名和填报周期。
- 正式提交前请确认业务分类、责任单位、统计周期及关键数值准确无误。
