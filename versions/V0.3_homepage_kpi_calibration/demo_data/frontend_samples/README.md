# ESG 智能入库 · 样例文件

本目录提供**可真实读取内容**的样例文件，用于 Workspace「ESG智能入库」演示：上传 → 解析 → 字段摘要 → 任务关联。

不依赖外部 LLM Key；后端对约定格式做确定性字段抽取。

## 推荐演示文件

| 文件 | 格式 | 说明 |
| --- | --- | --- |
| `罗宜高速_2026年7月水保监测月报摘要.csv` | CSV（字段,值） | 主演示文件；数值与 mock 默认值不同，便于核对「是否读到文件」 |

可识别字段示例：

- 资料类型 / 周期 / ESG 模块 / 责任单位
- 项目标段 / 工程对象
- 扬尘超标次数、噪声超标次数、水保问题数量
- 建议关联任务、建议关联指标（E03）

## 点击演示步骤

1. 启动前后端（一键启动或分别启 Vite + `server/app.py`）。
2. 打开 `http://localhost:5174/#/workspace?t=smart-upload`（或顶栏进入数据填报 → ESG智能入库）。
3. 点击「选择本地文件」，上传本目录下的 CSV。  
   - 也可从浏览器直接打开 `/samples/罗宜高速_2026年7月水保监测月报摘要.csv` 下载后再上传。
4. 等待右侧「AI解析摘要」刷新：应出现 **扬尘超标 3 / 噪声超标 2 / 水保问题 7**、责任单位「罗宜高速项目安全环保部」、标段「第二合同段」等**文件内原文**。
5. 「AI智能推荐」中应出现匹配「2026年7月水保监测月报」类任务（库内有对应 `upload_task` 时）。
6. 勾选任务后点击「确认入库并关联」，核对成功提示中的 DocumentID / 关联任务。

## 如何自证「不是假数据」

| 核对点 | 文件内值 | 旧规则默认（仅文件名推断时） |
| --- | --- | --- |
| 扬尘超标次数 | **3** | 1 |
| 噪声超标次数 | **2** | 1 |
| 水保问题数量 | **7** | 5 |
| 监测日期 | **2026-07-18** | 2026-07-13 |
| 责任单位 | **罗宜高速项目安全环保部** | 安全环保部 |

若页面显示左侧「文件内值」，说明内容解析已生效。

## 格式约定（可扩展同类文件）

CSV 两列：`字段,值`（UTF-8，建议带 BOM 亦可）。

支持的字段名（中英文 key 均可）：

`资料类型` / `document_type`、`资料周期` / `period`、`责任单位`、`项目标段`、`工程对象`、`扬尘超标次数`、`噪声超标次数`、`水保问题数量`、`建议关联指标编码` 等。

TXT 可用 `字段：值` 或 `字段=值` 行格式，解析器同样支持。
