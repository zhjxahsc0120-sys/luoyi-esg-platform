# 上级安全检查 · 核查项与现有台账缺口

## 常见核查项

- [ ] 较大及以上在管安全风险台账已更新并可导出
- [ ] 风险点责任人、标段、整改期限可核对
- [ ] 逾期未闭环风险有明确说明材料
- [ ] 现场防护与台账描述一致
- [ ] 应备资料目录与实件一一对应

## 台账缺口说明（占位）

正式回答中的在管风险件数、等级分布须调用 `GET /api/social/s02/risks`（`get_s02_risks`）及 KPI S02，与安全风险工作台同源。本文件不承载业务黄金数。

本表面向**上级检查组**备检，非部门内部自查清单。
