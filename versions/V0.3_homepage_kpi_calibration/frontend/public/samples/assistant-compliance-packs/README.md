# ESG 智能助手 · 上级检查合规资料包

本目录供 `/#/assistant` **应对上级部门检查**场景：同一回答返回 **库驱动合规口径** + **「下载资料包」**。

设计说明见：`_handoff/ESG智能助手_库驱动问答与合规资料包设计_V0.2_20260727.md`（含 V0.3 附录：环保包 11 类目录）

> **口径：** 非「某部门迎检自查清单」；面向上级监管/检查组备检。  
> **环保包主口径：** 11 类应备资料 + 具体文件归集/待补齐；不以「应备仅 4 项」作标题。

## Chat UX

回答卡片：结论（库口径）→ 11 类进度表 → PackageCard（类别/文件/已归集/待补齐/未闭环/闭环率）→ 主按钮 **「下载资料包」** → 上表 zip。
