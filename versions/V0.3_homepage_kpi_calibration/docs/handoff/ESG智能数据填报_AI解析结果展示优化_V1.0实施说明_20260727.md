1. 打开工作台 → ESG智能数据填报
2. 上传含「2026年5月」或监理月报关键字的文件（或任意支持格式，会回落到默认 demo）
3. 等待 stage 跑完后确认：
   - 报告为叙事流，非大表主内容
   - 入库状态为「待业务确认」

4. 执行：`npm run check`
