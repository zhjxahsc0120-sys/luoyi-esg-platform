## 1. 目标与边界

### 1.1 目标

首页点击 **S02 KPI**，或地图业务链/安全风险点空间对象点击 → 进入地图中心工作台：

- 右侧一级总览（等级筛选 + 清单分页）
- 地图高亮对应 GIS 要素；工具栏「安全风险点」开关与工作台一致
- 选中后：左上 **L2 管控详情壳**（进展轨 / 材料）+ 右下角摘要卡（可再点「查看管控详情」）

### 1.2 本阶段不做

- 不回退 / 不改动 S01 数据层与 S01 UI 回退轨道
- 不推倒首页 ESG 总布局；不改 E01–E04 / S03–S04 / G 组
- 不做真实督办审批流、不做「演示/测试/未确认」UI 角标
- 不新建独立案卷表（L2 叙事由明细 API 结构化返回，与 seed 对齐）

| # | 标准 |

| 1 | 点 S02 KPI → 右侧工作台打开，左侧地图进入工作台模式 |

## 2. 甲方口径对照表

| 甲方要点（7.14 / 领导首页需求） | 本系统落地 |
|--------------------------------|------------|
| KPI：仍处于施工/监控/管控且等级为**较大或重大** | `risk_level IN ('重大','较大') AND control_status <> '已销号'` |
| 重大 / 较大独立维护 | Tab「重大」「较大」；台账 `risk_level` 分列 |
| 同一工点多项分别统计 | 如 K32+500 吊装与基坑分两条（S02-003 / S02-004） |
| 编号由建设单位统一维护 | `businessCode` = `S02-xxx`（由 id 43000x 派生） |
| 进入在管起点：开工相关 | `control_start_date`；隧道项对齐开工令 2026-05-08 |
| 解除/降级/完工由建设单位评估 | `control_status='已销号'` + `cancelled_date`；L2 文案「建设单位确认」 |
| 与周报冲突以专项清单为准 | L2 材料角色「专项清单」优先表述 |
| 首页按工点展示 | 列表展示 `location`（含标段+桩号+工点） |
| 字段：编号、工点、等级、开始、状态、解除 | API / L2 / 摘要卡覆盖 |
| 细项类型：隧道、高边坡、深基坑、高墩、吊装、爆破、起重、导改等 | `risk_type` + seed 覆盖 |
| UI 禁演示角标 | 使用「持续管控」「建设单位确认在管」 |

**待规则化（不写死代码）：** 评估材料模板、审核人、短周期「按需纳入」准入细规。

### 2.1 KPI SQL（沿用）

```sql
SELECT COUNT(*) FROM safety_risk_point
WHERE risk_level IN ('重大', '较大')
  AND control_status <> '已销号'
```

一风险点计 1；已销号不计。V0.2 seed 后期望：**8**（重大 2 + 较大 6）；本月销号 2。

## 4. 信息架构

```
首页
 └─ 点 S02 KPI / 地图 S02 业务链
      ├─ 右侧 S02WorkspacePanel（L1）
      │    ├─ 等级统计 Tab
      │    ├─ 风险点清单（分页）
      │    └─ 关闭 → 恢复地图状态
      └─ 地图区
           ├─ 关联要素高亮
           ├─ S02ClosureAnalysisPopover（L2：辨识→在管→管控→销号）
           ├─ S02MapSummaryCard（摘要 +「查看管控详情」）
           └─ 工具栏「安全风险点」开关
```

主题强调色：**S 组蓝 `#2f9cff`**。

### 4.1 L2 行为（对标 E02）

| 区块 | 内容 |
|------|------|
| 进度轨 | 辨识 → 在管 → 管控 → 销号 |
| 当前状态 | 等级徽章 + 持续管控 / 已销号 +「建设单位确认在管」 |
| 参与方 | 建设单位 / 施工单位 |
| Tab「管控进展」 | 状态轨迹（辨识登记→进入在管→持续管控…） |
| Tab「管控材料」 | 专项清单 / 专项方案 / 监测 / 许可等登记项 |

入口：清单行点击、地图要素点选、摘要卡「查看管控详情」。关闭 L2 = 取消选中。
