## 1. 导航命名与路由

### 1.1 文案

| 候选 | 评价 |
|------|------|
| **碳核算** | **推荐**：短、对齐 E04「累计碳排放 / 核算边界」 |
| 碳排放 | 偏指标名，顶栏略窄 |
| 碳足迹 | 偏面板文案，与「核算」运营台略偏 |

**冻结推荐：** 顶栏与页标题均用 **「碳核算」**。

### 1.2 路由

| 项 | 值 |
|----|-----|
| Hash 路由 | **`/#/carbon`**（`name: 'carbon'`） |
| 深链 | `?t=` 同步二级 Tab，例：`/#/carbon?t=overview` |

### 1.3 顶栏顺序（HeaderNav / `navItems`）

```
工作台首页 → ESG智能助手 → 数据填报 → 碳核算 → 月报
```

`key`：`carbon`；`label`：`碳核算`。  
「月报」由姊妹页设计定义；本页实施时 **允许** 在 `navItems` 中一并挂上两项（最小接线），但 **禁止实现月报页内容**。

平台壳 `handleNav*` 需在 Dashboard / Workspace / Assistant / 碳页 /（若已存在）月报页中补 `carbon` → `router.push('/carbon')`（及对称的 `monthly-report` 跳转若 nav 已含该项）。**禁止**改 HeaderNav 视觉结构。

## 2. 壳层与版式规则（MUST）

与 Workspace / Dashboard / Assistant **同一大屏壳**：

1. 外层：`screen-wrapper` + **`screen-canvas` 1920×1080 + scale**（对齐 `WorkspacePage`）
2. 顶区：`HeaderNav`，高度 `var(--dashboard-header-h, 80px)`
3. 二级：仿 `WorkspaceNav` 的 Tab 条（本页私有 `CarbonNav`）
4. 主区：可读运营工作台；优先复用 **Workspace** 视觉语言：`.ws-panel` / `.ws-btn-*` / `--ws-*`（`workspace.scss` 可按需 import，或新建 `carbon.scss` **仅扩展同类 token**）
5. 背景：与 Workspace 同系深色渐变（`#020b18` → `#051a32`）
6. **禁止**：首页 `CarbonBenefitPanel` 布局克隆；演示 chrome；把月报内容塞进本页；以 E04 模态作为整页主内容

## 3. 信息架构（IA · 仅碳）

| `?t=` key | 标签 | 一句话职责 |
|-----------|------|------------|
| `overview` | **概览** | 累计排放主值、构成摘要、口径要点 |

## 4. 各 Tab 内容规格

### 4.1 概览（`overview`）

| 区块 | 内容 | 数据 |
|------|------|------|
| 主 KPI | 项目累计碳排放；单位 tCO₂e；可取整展示，**禁止硬编码 6175** | `GET /api/dashboard/panels` → `carbon.metrics` |
| 构成摘要 | 来源占比（油 / 电 / 材料等 `carbon.sources`） | 同上 |
| 口径要点 | 施工用油 + 用电 + 主要材料；**运输暂不纳入**；起点 **2026-05-08**；核算期 **2026-05 — 2026-07**；精确累计约 **6174.99**（以 API/库为准） | 甲方 7.14 / E04 基线；数值走 API |
| 可选 | 减排/措施一行（若有 `reductions`） | panels |

可选「打开完整核算视图」：可 **懒挂** `E04CarbonEmissionModal` 作补充，**不得**作为本 Tab 唯一内容，**不得**作为整页主路径。

权威口径：`_handoff/E04_甲方7.14数据重构与设计基线_20260724.md`。

### 4.2 构成与边界（`boundary`）

| 区块 | 内容 |
|------|------|
| 边界表 | 纳入：燃油、电力、主要材料；不纳入：运输（暂）；设备不单列防双计 |
| 来源构成 | `sources` 名称 / 占比 / 可选量值 |
| 禁止 | 改 E04 模态内部；改 seed 主值；编造行；月报字段 |

### 4.3 明细（`detail`）

| 区块 | 内容 |
|------|------|
| 明细表 | 若 `GET /api/carbon/benefit-overview` 有可用明细字段，只读表格；无则空态 + 口径提示 |
| 禁止 | 强制整页嵌 E04 模态；克隆首页环图专题 |
