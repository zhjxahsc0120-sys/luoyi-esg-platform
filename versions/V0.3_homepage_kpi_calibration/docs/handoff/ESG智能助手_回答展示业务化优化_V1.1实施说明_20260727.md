## 已完成

1. **业务回答卡片**（`AssistantMessage.vue`）统一结构：
   - 状态判断（含等级角标：正常 / 基本受控 / 存在风险 / 需重点关注）
   - 核心指标（数值 + 状态 + **业务含义**）
   - 重点关注 / 缺失资料
   - 数据依据（来源 / 统计时间 / 口径）
   - 建议操作
2. **上级检查能力保留并合并进卡片**：
   - `PackageCard` +「下载资料包」
   - 11 类统计 chips：类别 / 文件 / 已归集 / 待补齐 / 未闭环 / 闭环率
   - 检查类额外展示 11 类进度表；主叙事为准备状态 + 完整率 + 缺失项，而非「应备 4 项」
3. **推荐问题业务化**（环境 / 安全 / 检查 / 月报），检查类含「如果现在接受上级检查…」「应对上级环保检查…」
4. **前端问句 → questionId 映射**，保证新文案仍落到 Q01/Q02/C03 等意图
5. **API 回答经 `normalizeBusinessAnswer` 整形**为项目经理汇报口径；失败时可用 3 个 demo 结构示意

## 验收路径

打开 `/#/assistant`，依次点：

1. 当前环保风险情况如何？ → 首段状态判断 + KPI（含含义）+ 风险 + 依据 + 下一步  
2. 应对上级环保检查应准备哪些合规资料？ / 如果现在接受上级检查，主要风险是什么？ → 检查准备状态 + 完整率 + 缺失 + **下载资料包（11类统计）**  
3. 当前重大安全风险有哪些？ → 风险数量 + 关注点 + 建议
