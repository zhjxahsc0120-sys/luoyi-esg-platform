## 五、验证 SQL

```sql

  project_id, `key`, name, `value`, unit, hint, riskLevel, period_end
FROM v_esg_demo_dashboard_kpis
WHERE project_id = 1001
  AND period_end = '2026-08-04'
ORDER BY FIELD(
  `key`,
  'E01','E02','E03','E04',
  'S01','S02','S03','S04',
  'G01','G02','G03','G04'
```

重点断言：

```sql
SELECT
  MAX(CASE WHEN `key`='E04' THEN `value` END) AS e04_value,
  MAX(CASE WHEN `key`='S01' THEN `value` END) AS s01_value,
  MAX(CASE WHEN `key`='S03' THEN `value` END) AS s03_value,
  MAX(CASE WHEN `key`='G01' THEN `value` END) AS g01_value,
  MAX(CASE WHEN `key`='G02' THEN `value` END) AS g02_value,
  MAX(CASE WHEN `key`='G03' THEN `value` END) AS g03_value,
  MAX(CASE WHEN `key`='G04' THEN `value` END) AS g04_value
FROM v_esg_demo_dashboard_kpis
WHERE project_id=1001 AND period_end='2026-08-04';
```

预期结果：`0 / 89 / 100 / 12/12 / 2/2 / 4/4 / 正常`。
