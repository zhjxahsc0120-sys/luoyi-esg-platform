## 2. 执行步骤

### P3.1 Dashboard 接入

在 `DashboardPage.vue`（对标 E02）：

- `kpiKey==='E03'` → `openE03Workspace()`，**不要**默认开旧 `KpiDetailModal`  
- 与 E01/E02 **互斥**：开 E03 关另外两者  
- 右侧槽复用 `.dashboard-right` / E01·E02 工作台 class（可 `is-e03-workspace`）  
- ESC：先清选中，再关面板（与 E02 一致）  
- 地图业务链 target E03 → 进工作台并选中对应事项（多事项见 P3.5）  

### P3.2 `E03WorkspacePanel.vue`（一级）

对标 `E02WorkspacePanel`：

- 标题：**「水土保持问题闭环工作台」**（水保＝水土保持）；演示角标  
- 统计：全部｜整改中｜待复查｜待销项；**其中逾期**叠加（勿让用户以为与状态格五数相加）  
- 列表：水保类型、位置、状态、期限、逾期高亮、无法定位标识、演示角标  
- 分页默认每页 **3**；同分辨率不跳变；分页栏始终可见  
- 空态 / 加载 / 错误+重试  
- 关闭：退出工作台、清选中与高亮  
- 宽度复用 E01/E02 容器，勿另写死比例  

数据：`getE03Issues(scope)`；筛选切 category 时刷新列表并以 overview 为准。

### P3.3 `E03ClosureAnalysisPopover.vue`（二级）

- **地图锚定**弹窗（Teleport / 避让对标 E02；窄屏可翻左）  
- **内容顺序（冻结 §6.2）：**  
  1. **问题概况**（六项，不得只换标题抄 E02）  
  2. 闭环进度、责任链、状态轨迹、证据材料（页签：闭环进展｜证据材料）  
- 材料：预览（已实现）/ 下载 / 暂无材料；完整度展示（含 D07 notes）  
- 演示 GIS 免责声明固定展示  
- 异常态：加载中、失败+重试、无轨迹、无材料、GIS 不可用（安全默认位，不造假点）  
- **禁止**督办等伪入口  

### P3.4 关闭与空白点击（行为唯一）

关闭二级或点地图空白：

1. 保留一级筛选与页码  
2. 保留当前地图视角  
3. 取消事项选中与强高亮  
4. 恢复筛选结果的普通高亮  

### P3.5 地图联动

对标 E02 P3.4（`fitE02Issues` / `focusE02Issue` → E03 等价）：

- 打开 E03 / 切换分类：`fitE03Issues` 定位当前筛选关联要素  
- 选中 issue：`canLocate` 时 `flyToFeature(spatialLinks[0].featureId)`  
- 无空间：列表「无法定位」，不飞行  
- 高亮点/线/面；flyTo 扣除右侧面板 + 顶栏 + 底时间轴后的有效可视区  
- **一要素多事项：** 先出示选择列表，禁止随机开一条  
- 演示角标 + 免责，避免误解「该点真实发生此问题」  

### P3.6 类型与样式

- 使用 P2 的 `src/types/e03.ts` / `api.ts`  
- `layout.scss` 等：e03 workspace class，复用 e01/e02 槽，不另起信息架构  

### P3.7 前端验证

```bash
npm ci
npm run check
npm run build
```

后端若本单有小改：`python -m compileall -q server`  
（环境限制须在交付说明写明原因与替代验证。）
