### 2.6 P05 资料中心与档案

### 2.7 S01 任务办理中央弹窗

- 操作成功后刷新 P01/P02/P04。

## 3. 核心业务链路人工点测

### 链路 A：任务办理提交审核

1. 进入 `http://localhost:5174/#/workspace`；
2. 打开“我的上传任务”；
3. 选择一条资料完整的待提交任务；
4. 打开 S01 任务办理弹窗；
5. 点击“提交审核”；
6. 预期：
   - 页面提示“已提交审核”；
   - 任务状态变为“审核中”；
   - P04 审核结果出现新一轮“待审核”记录。

### 链路 B：审核通过

1. 进入 P04 审核结果；
2. 选择一条“待审核”记录；
3. 点击“审核通过”；
4. 预期：
   - 审核记录变为“已通过”；
   - 对应任务变为“已完成”；
   - 审核轨迹出现“审核通过”；
   - P01/P02 状态卡刷新。

### 链路 C：审核退回与补正再提交

1. 进入 P04 审核结果；
2. 选择一条“待审核”记录；
3. 点击“审核退回”；
4. 预期：
   - 审核记录变为“已退回”；
   - 对应任务变为“待补正”；
   - 右侧出现补正要求，状态为“待补正”；
5. 点击“进入补正”打开 S01；
6. 点击“重新提交审核”；
7. 预期：
   - 旧退回记录补正要求变为“已补正”；
   - 旧审核轨迹追加“补正提交”；
   - P04 出现新一轮“待审核”记录。

### 链路 D：智能入库并关联任务

1. 进入 P03 ESG 智能入库；
2. 上传一个文件；
3. 查看解析结果和候选任务；
4. 选择候选任务；
5. 点击“确认入库并关联”；
6. 预期：
   - 资料进入 P05 资料中心；
   - 候选任务资料完整度提升；
   - P01/P02/P05 自动刷新；
   - 重复文件能提示哈希重复。

### 链路 E：资料中心详情

1. 进入 P05 资料中心；
2. 切换 E/S/G 分类；
3. 点击资料列表行；
4. 预期：
   - 右侧详情切换；
   - 版本记录可查看；
   - 已关联任务可展示；
   - 无关联任务时显示空状态。
