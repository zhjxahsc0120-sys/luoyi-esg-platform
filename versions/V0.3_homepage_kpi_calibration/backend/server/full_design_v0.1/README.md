# 罗宜高速 ESG 数据库与接口完整设计 V0.1

本目录用于承接当前阶段的完整设计输出。

设计原则：

1. 不急于继续接入其他 11 个 KPI 弹窗；
2. 先把数据产生、确认、入库、审核、汇总、展示的链路定清楚；
3. S01 已作为技术路径验证样例，后续页面接入应以完整数据链路为依据；
4. 智能入库是数据源头，领导首页是结果展示，不应倒过来为了首页展示硬造接口。

## 当前阶段结论

建议进入“设计固化阶段”，暂缓继续大面积前端 API 接入。

推荐路线：

```text
智能入库数据库设计
→ 工作台主链路接口设计
→ 业务明细表与指标汇总设计
→ 领导首页 KPI 数据来源设计
→ 再按优先级接入页面
```
