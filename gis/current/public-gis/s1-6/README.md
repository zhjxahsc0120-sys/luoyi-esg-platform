# S1-6 首页地图交接说明

## 程序包内正式地图文件

- 配置：`layer-config.json`
- 默认基础图层：`layers/高速公路首页_道路生态关键要素_不含SPX.kml`
- 按需边坡图层：`layers/高速公路首页_SPX边坡_独立图层.kml`
- 源文件目录：`data/mapdata`

以上 KML 已复制到项目 `public` 目录。执行 Vite 构建时会自动进入
`dist/gis/s1-6`，把完整程序包交给同事后，不依赖 `Y:` 盘或其他外部资料路径。

## 加载规则

1. 页面初始化读取唯一配置入口 `layer-config.json`。
2. “道路生态关键要素”和“边坡 SPX”均随首页默认加载并显示。
3. 设计 KML 不再提供前台显隐开关，避免用户误关项目基础图。
4. SPX 在 Web Worker 中解析 91,919 条 LineString，并按 4 种原始样式批量
   生成为 4 个 Cesium Primitive，避免创建海量 Entity 导致页面卡死。
5. SPX 首次成功加载后保留 Primitive 缓存。关闭开关只隐藏，再次开启直接
   显示已有对象，不重复请求 KML。
6. 每层独立记录可见、加载中、已加载、透明度和错误状态。单层失败不影响
   底图、视角或其他业务模块。
7. 首页设置入口只管理数据库异常、超标、逾期、风险和闭环等业务图层。
8. 首次加载和“复位视角”按配置中的新道路中心线范围定位，不受外围设计要素影响。
9. 取弃土场和土场编号数据当前暂时隐藏，待源资料修正后再启用。

## 原始数据保护

基础层使用 `Cesium.KmlDataSource` 原样读取。SPX 只改变渲染组织方式，不拆分
或改写源文件，不抽稀坐标，也不改变每条折线的连接关系；按 KML 的 ABGR 颜色、
透明度和线宽分批绘制。透明度滑块只按原颜色 alpha 比例调整。
