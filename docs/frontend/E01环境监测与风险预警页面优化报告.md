## 1. 修改前问题

1. **右侧内部滚动**：风险列表区域固定高度 + `overflow: auto`，大屏上出现滑轨式查看，内容展示不完整。
2. **默认入口不合风险语义**：首页「环保风险预警」进入后，默认按全部监测点展示（Demo 接口 `openPoints` 含正常点），与风险预警入口预期不符。
3. **详情重复**：点击监测点后同时出现 GIS 地图摘要弹窗与右侧「监测点详情 / 基础信息 / 检测值 / 整改记录」，信息重复。

---

## 2. 修改内容

### 2.1 取消右侧内部滚动，改为分页展开

- 移除列表 / 详情区内部纵向滚动（不再使用列表 `overflow: auto`）。
- 右侧结构固定为：标题 → 统计 → 范围切换 → 业务分类 → 点位列表 → 分页。
- 每页固定条数（`PAGE_SIZE = 4`），更多点位通过「上一页 / 1 2 3 / 下一页」查看。

### 2.2 默认「风险监测点」+ 全量切换

- 新增范围切换：`[风险监测点] [全部监测点]`，进入默认 **风险监测点**。
- 风险模式：仅展示超标 / 异常 / 待整改等当前风险点（前端基于 `status` / `caseStatus` / `exceedMultiple` 过滤，不改 API）。
- 全量模式：展示接口返回的全部监测点（含正常点）。
- 某分类无风险时列表提示「当前分类暂无风险」。

### 2.3 保留三类环境监测业务分类

- 去掉「全部」筛选芯片，改为三类业务分类卡片：
  - 空气监测
  - 水质监测
  - 噪声监测
- 默认进入 **空气监测**。
- 切换分类同步更新右侧列表与 GIS 可见点位（`e01VisiblePoints`）。

### 2.4 点击点位仅保留 GIS 弹窗

- **删除**右侧固定详情块（监测点详情 / 基础信息 / 检测值 / 整改记录）。
- 列表点击流程：选中 → 地图定位/高亮 → 仅 GIS 摘要弹窗展示快速详情。
- 不再为右侧详情调用 `getE01EventDetail`。

### 2.5 GIS 弹窗作为快速详情

在既有 `E01MapSummaryCard` 上增强展示（不改趋势 API 契约）：

- 监测点编码 + 名称、类型、位置、状态
- 监测指标、当前值、标准值、超标情况
- 保留趋势图作为趋势入口

## 3. 页面交互说明

```
首页 KPI「环保风险预警」
  → 打开 E01 工作台
  → 默认：风险监测点 + 空气监测
  → 可切换：风险 / 全部；空气 / 水质 / 噪声
  → 列表点选或地图点选
  → GIS 定位 + 地图弹窗查看详情
  → 右侧仅保留列表与分页（无重复详情区）
```

### 验证说明 / Blockers

- 交互浏览器自动化（Cursor browser MCP）本轮不稳定（tab 创建后无法 navigate），未完成端到端点击录屏。
- 后端 Demo API `http://127.0.0.1:8765/api/environment/e01/events` 可连通（`code=0`，3 个监测点），Vite 代理 `/api` → `8765`。
- 若正式 MySQL 链路仅返回未闭环点（`overviewRule: open-points-only`），则「全部监测点」与「风险监测点」可视集合可能接近；Demo 全量点场景可区分。此为既有 API 数据范围限制，本次未改 API。
