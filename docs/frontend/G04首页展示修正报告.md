## 1. 修改前后展示

| 项 | 修改前 | 修改后 |
|---|---|---|
| 展示名称 | 内控检查 | **合规管理天数** |
| 数值 | 正常（V0.3 状态词，来自 API `value_text`） | **89 天**（前端 Demo 配置计算） |
| 单位 | （空） | **天** |
| KPI 编码 | G04 | G04（不变） |
| 首页卡数 | 12 | 12（不变） |

演示天数计算（前端独立配置，非 S01）：

```text
合规管理起算日 = 2026-05-08（G04_HOME_DEMO_DISPLAY.managementStartDate）
统计截止日     = 2026-08-04（对齐当前 Demo period_end）
天数 = DATEDIFF(截止日, 起算日) + 1 = 89
```

说明：数值可与 S01「安全生产天数」碰巧同为 89（同一项目开工日演示），但代码路径、配置常量与业务语义均独立，**未读取 `/api/dashboard/kpi/S01`，未改 S01 数据**。
