## 当前遗留问题

1. **E01/E02/E03/S02 地图高亮与点位叠加**：交接包 `TrafficGisOverview` 为 `designOnly` 设计底图，不再接收旧业务 marker/高亮 props；右侧工作台与摘要卡仍保留，但地图上不再绘制/高亮业务点位。需后续在交接包模块上做增量扩展（禁止拆分重构本次已迁入源码）。
2. **相机态 capture/restore**：交接包仅暴露 `flyToFeature` / `flyToSection` / `refreshLayer` / `resetView`；首页进出工作台时改为占位逻辑 + 必要时 `resetView`，无法精确恢复进入前视角。
3. **业务要素 flyTo**：仅当存在 `gisFeatureId` / `spatialLinks.featureId` 且设计图层实体能匹配时才有效；纯经纬度点位暂无 `flyToLonLat`。
4. **在线底图/地形**：依赖高德影像与 mars3d 地形外网；离线环境需配置 `VITE_TRAFFIC_BASEMAP_URL` / `VITE_TRAFFIC_TERRAIN_URL`。
5. **截图环境**：Cesium 在无 GPU 的 headless 下可能依赖 SwiftShader；本地人工浏览器验证更准确。
