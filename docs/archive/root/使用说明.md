# 本地预览使用说明

## 为什么不能直接双击打开？

本项目使用 Vue 3 + Vite 构建，产物为 ES Module（`type="module"`）格式的 JavaScript。
由于浏览器的 CORS（跨域资源共享）安全策略，直接双击 `index.html`（file:// 协议）会被拦截，导致页面空白。

## 启动方式

### 方式一：使用启动脚本（推荐）

双击 `启动本地服务器.bat`，脚本会自动检测 Python 或 Node.js 并启动本地服务器，同时打开浏览器。

### 方式二：使用 Python

```bash
cd E:\luoyi-esg-dashboard\dist
python -m http.server 8080
```

然后在浏览器打开：http://localhost:8080

### 方式三：使用 Node.js

```bash
cd E:\luoyi-esg-dashboard\dist
npx serve -l 8080 .
```

然后在浏览器打开：http://localhost:8080

## 停止服务器

在命令行窗口按 `Ctrl + C` 即可停止。
