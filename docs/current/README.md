# 罗宜高速 ESG 领导层看板

面向高速公路建设项目领导层的 ESG 数据可视化大屏，采用 Vue 3 + TypeScript + Vite 技术栈，聚焦 1920×1080 大屏展示场景。

## 技术栈

- **框架**: Vue 3 (Composition API + `<script setup>`)
- **构建工具**: Vite 5
- **类型系统**: TypeScript 5
- **状态管理**: Pinia
- **样式方案**: SCSS (自定义设计系统，无 UI 框架依赖)
- **图表库**: ECharts 5
- **图标库**: Lucide Vue
- **HTTP 客户端**: Axios (预留)

## 快速开始

### 环境要求

- Node.js >= 18
- npm >= 9

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

默认端口为 `5173`，浏览器访问 `http://localhost:5173` 即可预览。

### 生产构建

```bash
npm run build
```

构建产物输出至 `dist/` 目录。

### 预览生产构建

```bash
npm run preview
```

### 类型检查

```bash
npm run check
```

## 核心功能模块

### 1. 顶部导航区
- 平台标题 + 底部导航条的双层结构
- 7 个一级导航：工作台首页、合规底线管理、碳足迹与低碳增益、风险预警与督办、项目现场一张图、月报管理、资料与档案

### 2. KPI 指标区
- 三大分组：E 环境环保组、S 社会责任组、G 治理合规组
- 每组 4 个核心指标，含状态标签

### 3. GIS 地图主视觉
- SVG 绘制的路线地图（带光效、流动动画）
- 行政边界、敏感区、风险点、环保点位叠加
- 图层切换：全线、标段一/二、环保点位、风险点、无人机影像
- 罗盘、图例、卫星/无人机时序影像对比卡片
- 点位悬停提示

### 4. 合规保障与风险防控
- 4 项核心成效指标卡
- 成效构成条形图
- 重点保障事项清单

### 5. 碳足迹与低碳增益
- 3 项碳指标卡
- 碳足迹来源构成环形图
- 主要减排措施清单

### 6. 月报准备与输出
- 月度进度环形进度条
- 待补资料清单表格

### 7. 建设阶段时间轴
- 11 个建设阶段节点
- 已完成 / 进行中 / 待完成 三种状态
- 当前阶段脉冲动画

## 设计规范

### 适配目标
- **主目标**: 1920×1080 大屏（100% 缩放，无滚动、无裁切）
- **兼容**: 1366×768 等比例缩放
- 采用 CSS 变量 + flex/grid 布局，固定区域尺寸比例

### 色彩体系
- 主背景：深海蓝 `#020b18`
- 面板背景：半透明深蓝 `rgba(5, 18, 38, 0.88)`
- 主题色：青色 `#00e5ff` / 蓝色 `#2f9cff`
- 状态色：绿色 `#69e36f` / 橙色 `#ffb347` / 红色 `#ff4f5e` / 紫色 `#a66cff`

## 交付说明

### 当前交付物

- 基于 Mock 数据的可运行原型
